# Experimental Features

Features moved here are NOT part of core finals flow.
They may be re-integrated after MVP ships.

**Moved on:** 2025-12-03

## What's Here

This folder contains experimental features that are not part of the MVP finals prep experience:

- Knowledge graph visualizations
- Advanced personalization beyond finals
- User memory features
- Spaced repetition systems
- Advanced search explorations
- Lab/preview features

## Why Moved

These features add complexity without directly improving the core finals prep workflow. The MVP focuses on four core features:

1. **Finals Pack** - Clean, trustworthy practice materials
2. **Diagnostic** - Practice final with FRQ grading + results
3. **Study Plan** - Daily tasks based on diagnostic
4. **Study + Chat** - Explicit content + AI tutor

## Re-integration Plan

After the MVP is validated with real students, we can selectively re-integrate features from this folder based on:
- Student feedback and usage patterns
- Impact on core metrics (exam scores, study completion)
- Technical stability and maintenance costs

## Feature Flags

To temporarily enable experimental features during development, use feature flags in `src/lib/featureFlags.ts`.
